# 純機械值域

本檔是值域的唯一居所。CLI 只檢查值在值域內，⛔ 不判轉移是否合法、⛔ 不判內容。

| 概念 | 值 |
|---|---|
| 階段（5） | 需求／規劃／執行／審核／結案 |
| 狀態（6） | 待辦／進行中／待確認／阻塞／完成／停止 |
| 角色（6） | 需求方／PM／研究者／規劃者／執行者／審核者 |
| 風險影響（3） | 一般／重要／高風險 |
| 緊急性（3） | 一般／限時／緊急 |
| 審核結果（4） | 批准／退回執行／退回規劃／退回需求 |
| 研究的網路使用（3） | 必要／允許／禁止 |

- **審核結果寫在留言，⛔ 不是狀態值、⛔ 不是欄位。**
- 角色值只用於載入該角色的規則與必要清單，以及規則適用面。
- 狀態的唯一居所見 github.md；退回的機械形狀見 flow.md。

## ⛔ 不存在的值域

⛔ 無轉移表；⛔ 無「退回」狀態值（退回是事件）；⛔ 無級別（T0–T4）；⛔ 無模型或模型家族值域；⛔ 無任務類型值域（部署／維護是任務類型，但不是機械值）；⛔ 無工作包值域或工作包狀態；⛔ 無任何計數器。

新增值域等同改變流程形狀，一律另立獨立需求，⛔ 不由模組、專案層或任務層加值。
