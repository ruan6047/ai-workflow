# 架構參考 · 審核

## 立即契約

審核涉及架構約束或文件更新時，先讀本檔「操作細則」與 [wfx/docs/ARCHITECTURE.md](../../../docs/ARCHITECTURE.md) §2／§5，只核本卡有效契約及受影響證據，不重審整本。

## 操作細則

本檔按角色／階段提供立即入口；操作細則僅由受派內容角色依入口觸發讀取。

獨立核對本次涉及的有效約束、核定交付與必要文件更新，沿用仍有效的證據，只有缺口、矛盾或受影響部分才作必要增量複查；不重審整本架構，不把候選或歷史背景加成驗收。
文件效力及衝突處置見 `wfx/docs/ARCHITECTURE.md` §2／§5，審核結果仍依 `stages/審核.md`；證據不足如實說明，不自行核准架構例外。
使用 CodeGraph 時依既有 `modules/codegraph/審核.md`，工具輸出不賦予架構規範效力，工具缺席不影響獨立審核責任。
