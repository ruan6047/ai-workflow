# 架構參考 · 需求

## 立即契約

確需架構參考時，先讀本檔「操作細則」與 [wfx/docs/ARCHITECTURE.md](../../../docs/ARCHITECTURE.md) §1–§3；區分現況、有效約束與候選，缺文件不阻不受影響工作，不自行擴張本卡。

## 操作細則

本檔按角色／階段提供立即入口；操作細則僅由受派內容角色依入口觸發讀取。

本卡確需專案架構 [Architecture] 參考時，沿 `.wf/` 既有定位讀原本體與適用決策，分清現況、有效約束、核定目標與候選，不把整份文件變成本卡需求。
初次建立或接入既有文件的用法見 `wfx/docs/ARCHITECTURE.md` §1–§3；權威仍依 `core/boundaries.md` §3。
缺文件不阻塞不受影響的任務；需要建立完整架構且構成另一主要成果時，走既有共同入口，不附帶擴張本卡。
