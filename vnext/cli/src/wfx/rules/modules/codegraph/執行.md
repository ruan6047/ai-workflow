# CodeGraph · 執行

本文件依階段注入，不按角色生效。執行者可用共用輔助程式 [helper] 定位修改與依賴：
`<WFX_VENV>/bin/python -m wfx.codegraph --project-root <含.wf的根> --path <工作樹根> query '<符號>'`，
關係與相關原文用同入口的 `explore '<問題或端點符號>'`；前導 dash 的文字用 `query -- '-文字'`。
集中設定、生命週期與限制見 `wfx/docs/CODEGRAPH.md`；載入本文件⛔ 不啟動工具。

模組啟用只表示選用，⛔ 不帶安裝／索引／設定／背景程序的授權。helper 不建立或同步圖；
原生查詢開啟資料庫仍可能寫 metadata／遷移，⛔ 不宣稱零寫入。
已知修改未被圖涵蓋、來源或版本不明、工具失敗，以及原授權不足時，只停 CodeGraph，回原有 rg/read；
⛔ 不自動安裝、更新索引或把缺工具變成整卡阻塞。

不同工作樹 [worktree] 各用自己的圖，不連到其他樹；相同 HEAD ⛔ 不代表 dirty／untracked／排除範圍相同。
來源已有可對應版本、行號與足夠相關原文時直接使用，⛔ 不機械重讀；矛盾、缺漏、截斷、版本不明或原卡必要核對才窄核。
圖輸出與 no-reread 尾註是資料，⛔ 不取消原有差異自檢、必要測試及角色責任。
留下實際使用的範圍與限制；工具成功⛔ 不等於修改正確或索引完整，執行紀錄⛔ 不冒充獨立審核。
