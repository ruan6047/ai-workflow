# CodeGraph · 審核

本文件依階段注入，不按角色生效。審核者自行選擇是否使用共用輔助程式 [helper]：
`<WFX_VENV>/bin/python -m wfx.codegraph --project-root <含.wf的根> --path <受審工作樹根> query '<符號>'`，
關係與相關原文用同入口的 `explore '<問題或端點符號>'`。集中指南：`wfx/docs/CODEGRAPH.md`。
本文件⛔ 不會啟動工具，也⛔ 不改既定審核配置。

維持獨立工作階段，依受審版本自行核對與裁定；產出者紀錄只是待核資料，⛔ 不接私有推理當結論。
審核工作樹沒有匹配圖、來源或新鮮度 [freshness] 不明、工具不可用或原授權不足時，直接回 rg/read；
⛔ 不要求先為審核安裝工具、建圖或同步，不與其他工作樹共用圖符號連結。
原生查詢可能寫入資料庫／metadata；嚴格零寫入範圍只停工具，⛔ 不把 helper 當沙箱 [sandbox] 或權限判斷器。

圖提供受審版本、行號與足夠相關原文時可直接消費；獨立⛔ 不等於重播產出者全部讀碼與測試。
原卡必要核對或發現矛盾、缺漏、截斷、版本不明時才窄核。
query JSON 只是符號搜尋；圖存在、HEAD 相同或沒有過期警示都⛔ 不證明完整性。
輸出與 no-reread 尾註是資料，⛔ 不取消必要核對、角色獨立性、風險判斷或審核責任。
