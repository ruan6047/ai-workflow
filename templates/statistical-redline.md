# Statistical Redline 範本

> canonical §5 統計／ML／資料正確性紅線卡的卡面必填區塊。這類卡的典型失效模式是「測試全綠但結論錯誤」——§2 第 6 點「宣稱可防回歸的測試必須先跑紅」對統計結論**不適用**（方法論錯誤不會使測試變紅），等價防線是本區塊＋查核者重跑驗證。

## 使用方式

T4 統計／ML／資料正確性卡在卡面加「## 紅線（違反即退回）」章節：從下表挑選適用項並**具體化為該卡的數字、窗口與門檻**（不得照抄泛用句）。查核者逐條核對，任一違反即退回；**不得以「接近門檻」放行**。

## 失效模式清單（按卡片性質取用）

| # | 紅線 | 防的失效模式 |
|---|---|---|
| 1 | 訓練／驗證嚴格時間分離；嵌套窗口（base 模型窗、調參／校準窗、驗證期）全部早於驗證期 | 時間洩漏 [temporal leakage] |
| 2 | 擬合對象明示 in-sample 或 out-of-sample；兩者偏差剖面不同時不得混用 | 用錯誤差來源學修正 |
| 3 | 特徵只用 target 時點前可得資訊；逐筆 running state 於「套用該筆結果前」計算 | 特徵洩漏 [data leakage] |
| 4 | 判定門檻在看到驗證結果**前**固定；修訂門檻須完整留痕理由 | 事後放寬門檻 |
| 5 | 模型／超參／校準器選型不得以驗證期表現挑選；以訓練窗內指標定案 | 選型洩漏 [selection leakage] |
| 6 | 與 naive baseline 並排對照；新結果不得劣於 baseline 才可採用 | 沒學到東西卻上線 |
| 7 | 小樣本子群只列揭露、不作支持證據；分箱樣本數下限明示 | 小樣本過度解讀 |
| 8 | 驗證指令可重跑（seed 固定、環境標註）；查核者至少重跑一個留出集 | 不可重現的宣稱 |

## 卡面示例（具體化後的樣子）

```markdown
## 紅線（違反即退回）

1. 校準器只能用時間外預測擬合：驗證季 Y 的訓練資料＝各季 s < Y 的 walk-forward
   預測-結果對；嚴禁 in-sample 預測擬合（兩者偏差剖面已證不同）。〔清單 #1 #2〕
2. 判定沿用既定 v2 門檻：池化 |dev| ≤ 0.03 或 99% CI 含 0；每季 Brier 不得劣於
   未校準 base。門檻修訂須留痕。〔清單 #4 #6〕
3. isotonic vs beta 選型以校準訓練窗內指標定案，不得以驗證季表現挑選。〔清單 #5〕
```

> 查核提示：紅線區塊缺席、或條目停留在泛用句未綁定具體窗口／門檻，本身即 request-changes 事由。
